# ai-main adapter for pi (direct)
You are running inside plain `pi` (agent dir ~/.pi/agent). No launcher.
The extension ai-main-brain.ts reads the shared brain live on every run (not copied):
- ~/.hermes/state/ORACLE.md (generated by ai-main/bin/oracle-recap): who the user is, hot rules, memory index.
- ~/ai-main/build/full/SYSTEM.md (generated by `aimain build`): profile, style, workflow, rules.
Every bash / ClickUp / graphify tool call passes ~/.claude/hooks/guard.sh (extension guard.ts, fail-closed). A "BLOCKED by guard.sh" result is final: stop and ask the user; never retry the same action in another form.
