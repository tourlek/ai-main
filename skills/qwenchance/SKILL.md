# Keep work moving

- Detect repeated actions with no new information. Re-reading to recover an exact detail or rerunning a check after a meaningful change is not a loop.
- When stalled, state known evidence and the missing discriminator, then choose a different bounded action. Retry only with a concrete reason it could produce new evidence; respect harness-specific retry restrictions.
- Verify each coherent change, not every textual edit. Batch dependent edits before the relevant check.
- Use runtime context warnings or measured capacity, not file counts, turn counts, or internal word counts, to decide on compaction/handoff.
- Continue approved work while capacity permits. Use native compaction/continuation when available; hand off only when requested or runtime limits prevent safe continuation.
- Preserve a concise handoff containing scope, branch/worktree, changes, checks, blockers, and next action. Save it only where writes are permitted; otherwise return it in chat.
- Handoff never authorizes a commit, push, or switching a governed runner protocol. Do not claim unfinished acceptance criteria passed.
